## 🖼️ Manipulation d'images PPM en C++

Projet pour apprendre à programmer en C++ tout en manipulant des images au format PPM.

## 🔧 Fonctions réalisées

- Conversion en niveaux de gris
- Inversion des couleurs
- Extraction d'une partie de l'image
- Symétrie verticale
- Rotation à 90°
- Création d'images de test

## 📚 Notions utilisées

- Fonctions C++
- Fichiers (`ifstream`, `ofstream`)
- `struct`
- `vector`
- Tableaux 2D dynamiques
- Boucles
